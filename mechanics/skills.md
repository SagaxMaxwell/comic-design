# 技能与流派

## 技能的来源

技能不是系统自动发放的能力，而是角色长期重复某种有效行为后形成的战斗习惯。

## 四种技能来源

### 师傅传授

师傅传授的不是技能名称，而是方法和思考方式。

例如：

- 佣兵教狭窄通道里的短剑战。
- 猎人教如何通过风向判断魔物位置。
- 铁匠教如何观察武器重心。
- 老法师教如何节省魔力。

### 流派选择

流派像现实中的专业方向。越专精某个方向，就越可能牺牲其他可能性。

可选方向包括：

- 轻剑流：速度快，依赖闪避和反击。
- 重剑流：破坏力强，但消耗大、行动慢。
- 盾剑流：保护队友、控制位置，输出较低。
- 陷阱与短兵流：擅长伏击和地形战。
- 远程流：依赖距离、视野和弹药管理。
- 支援流：强化队友、治疗、侦查和控制。

### 自己开发

主角可以因为反复遇到同一个问题而逐渐创造自己的解法。

例如：

1. 正面挡不住敌人的力量。
2. 尝试使用盾牌改变攻击方向。
3. 发现墙壁、斜坡和绳索可以共同卸力。
4. 经历失败和受伤后改进动作。
5. 最终形成只属于自己的战斗技术。

### 从魔物身上理解战斗

打败魔物后，不一定直接获得技能，但可以获得理解：

- 从蜘蛛身上学习黏性、绳索和伏击。
- 从蜥蜴人身上理解尾部平衡和重心。
- 从石像身上理解钝击比斩击更有效。
- 从隐身魔物身上学习依靠声音、气流和脚印。
- 从群体魔物身上学习控制敌方阵形。

## 技能必须有边界

- 熟练某个招式不代表能在所有环境使用。
- 重伤、疲劳和恐惧会影响技能发挥。
- 技能需要不断维护和训练。
- 别人可以学习动作，却不一定能复制角色的经验和判断。
